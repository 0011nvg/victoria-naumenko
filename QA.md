# Проверка редизайна — 30 октября 2026

Ветка `redesign/bilingual-2026`. Проверено в облачном Chromium (Playwright) на локальной копии сайта.

## Аудит прежней версии: что изменено

| Было | Решение |
|---|---|
| Только русский язык | Две адаптированные версии: RU (корень) и EN (`/en/`), отдельные метаданные, hreflang, Open Graph |
| Сайт не продавал занятия, единственный контакт — ВКонтакте | Раздел «Занятия» (EN, РКН, РКИ / в EN — RFL и RAL), Telegram как основной канал записи, почта, ВК, плавающая кнопка записи на телефоне |
| Разделы «Направления» и «Мой подход» дублировали биографию | Объединены в «Обо мне»: 4 роли + одна ключевая мысль «ИИ помогает. Учитель решает.» |
| Достижения — три строки текста | Отдельный блок «Признание»: «Флагманы образования» крупно, квалификация, наставничество, конкурсы, методическая работа |
| Скриншоты проектов от предыдущей версии | Новые снимки актуальных версий (десктоп + телефон) в рамке браузера |
| Системный шрифт Arial | Собственные шрифты с кириллицей, загружаются с сайта |
| Шаблон `template.html` + `content.json` | Единый генератор `tools/build.py` и два файла контента |

## Результаты

| Проверка | Результат |
|---|---|
| Ширины 320, 360, 375, 390, 414, 768, 820, 1024, 1280, 1440, 1920 — RU и EN | 22/22: горизонтальной прокрутки нет, все изображения загружены, ошибок JS и консоли нет |
| Переключатель языка | RU#projects → EN#projects (раздел сохраняется); выбор запоминается; повторный визит на корень после выбора EN → `/en/`; после выбора RU — остаётся RU |
| Аккордеон услуг | Открыт первый пункт; при открытии другого предыдущий закрывается; без JS работает нативно (`<details>`) |
| Мобильное меню | Открытие/закрытие, Escape, закрытие по выбору раздела, фокус переходит в меню |
| Клавиатура | Порядок: «Перейти к содержанию» → логотип → меню → переключатель языка → Записаться; видимый фокус |
| Без JavaScript | Весь текст, меню, переключатель языка, аккордеон и контакты доступны; переполнения нет |
| prefers-reduced-motion | Бегущая строка, смена направлений, параллакс и появление блоков отключаются, контент виден сразу |
| Контраст (WCAG AA) | Основной текст на тёмном 16:1+; вторичный 8:1+; служебные подписи ≥ 4,6:1; лайм-кнопка 15,9:1; текст на светлых блоках 7,6:1; фиолетовые метки на светлом 5,0:1 |
| Ссылки | Внешние — только Telegram, ВК и три опубликованных проекта (не репозитории), все с `noopener`; почта — `mailto:`; все якоря существуют (`tools/check.py`) |
| SEO | Уникальные title/description на каждом языке, canonical, hreflang ru/en/x-default, Open Graph и Twitter с отдельными карточками 1200×630, JSON-LD ProfilePage/Person, sitemap с языковыми альтернативами |
| Вес | Страница без внешних запросов; шрифты 102 КБ, портрет 15–30 КБ, скриншоты проектов 27–75 КБ (WebP, lazy-load) |
| Сборка | `tools/build.py` детерминирована; `tools/check.py` — OK; `node --check script.js` — OK |

## Границы проверки

Firefox и Safari/WebKit в среде проверки недоступны; физические iPhone и Android не использовались. После публикации стоит открыть сайт на телефоне в Safari и Chrome. Ссылки на внешние сайты проверены по адресам, сами страницы проектов сняты с их актуальных исходников в репозиториях.
