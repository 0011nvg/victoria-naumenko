# Проверка версии от 30 октября 2026 года

## Что изменено по результатам аудита

1. **Первый экран — исправлен.** Вместо большого абстрактного контура добавлен настоящий портрет автора. Имя, профессиональная роль и переход к проектам разделены по иерархии.
2. **Знакомство — исправлено.** Биография объясняет связь повседневных школьных задач с авторскими решениями. Повторы сокращены.
3. **Проекты — исправлены.** Три крупные карточки с фактическими скриншотами, описанием аудитории и прямыми ссылками. LEXIGO и практикум РКН отмечены «В разработке».
4. **Направления и достижения — исправлены.** Четыре направления представлены отдельными строками; достижения — завершённым блоком без галереи и технических заглушек. Новые награды и даты не придуманы.
5. **Подход — исправлен.** Три конкретных принципа, включая ответственность учителя при использовании ИИ.
6. **Контакты — проверены.** Только ВКонтакте. Телефон, почта и ссылка на GitHub в контактном блоке отсутствуют.
7. **Мобильная навигация — исправлена.** На телефоне доступны все разделы через меню; без JavaScript ссылки остаются видимыми.

## Границы проверки

Адаптивность проверялась в облачном Chromium с фреймами заданной ширины. Вертикальная полоса прокрутки занимала 15 px (например, ширина фрейма 390, доступная ширина документа 375). Это не проверка на физическом iPhone, не Safari/WebKit и не замер мобильного подключения. Lighthouse, полная проверка экранным диктором и включение системной настройки reduced motion на реальном устройстве не выполнялись. Поддержка reduced motion проверена по CSS и JavaScript.

Для следующего релиза: `python3 tools/build.py`, `python3 tools/check.py`, `node --check script.js`; затем проверить изменённые разделы в браузере. Инструкции по публикации и обновлению находятся в README.
