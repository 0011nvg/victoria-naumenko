# Виктория Науменко — персональный сайт (RU / EN)

Опубликованный адрес: https://0011nvg.github.io/victoria-naumenko/ · английская версия: https://0011nvg.github.io/victoria-naumenko/en/

Статический двуязычный сайт без фреймворков, CDN, аналитики и серверной части. Шрифты (Manrope, Cormorant Garamond, JetBrains Mono, лицензия OFL) лежат в `assets/fonts/`, поэтому сайт не зависит от Google Fonts. Весь текст находится в HTML: содержание, ссылки и навигация работают без JavaScript.

## Концепция «Два алфавита»

Глубокий ночной синий фон, мягкое фиолетово-бирюзовое свечение и один сигнальный цвет — лайм — для всех действий (записаться, открыть проект). Крупный гротеск в паре с курсивной антиквой: латиница и кириллица на равных, как в работе преподавателя двух языков. Контурные буквы «A» и «Я» в первом экране — фирменный знак сайта.

## Структура

| Файл | Что внутри |
|---|---|
| `content/ru.json` | Все тексты русской версии: меню, первый экран, занятия (3 направления), обо мне, признание, проекты, контакты, метаданные |
| `content/en.json` | То же для английской версии (2 направления: RFL и Russian as an Additional Language) |
| `tools/build.py` | Разметка страниц; собирает `index.html`, `en/index.html` и `sitemap.xml` |
| `tools/check.py` | Автопроверка: сборка актуальна, якоря, ссылки, изображения, метаданные, контакты, отсутствие кириллицы в тексте EN |
| `styles.css` | Цвета (переменные в `:root`), типографика, адаптивность, reduced motion, печать |
| `script.js` | Переключатель языка с запоминанием выбора, мобильное меню, сменяющиеся направления, появление блоков, кнопка записи на телефоне |
| `assets/` | Портрет, скриншоты проектов (`projects/`), шрифты, иконки, карточки для соцсетей `social-ru.jpg` / `social-en.jpg` |

Не редактируйте `index.html` и `en/index.html` вручную — следующая сборка их перезапишет.

## Как обновить

1. Создайте ветку от `main`.
2. Измените текст в `content/ru.json` и/или `content/en.json`. В полях `title` и `quote` можно использовать `<em>` (курсивный акцент) и `<br>`.
3. `python3 tools/build.py` → `python3 tools/check.py` → `node --check script.js`.
4. Закоммитьте исходники и собранные страницы, откройте pull request, после проверки объедините в `main`. GitHub Pages публикует `main`, папку `/ (root)`.

**Добавить проект:** скопируйте объект в `projects.items` обеих версий, положите скриншоты 1200×825 и 390×780 (WebP) в `assets/projects/`, добавьте адрес проекта в `ALLOWED_EXTERNAL` в `tools/check.py`.

**Добавить цены/формат занятий:** допишите их в `lead` нужного направления и уберите фразу из `services.note`.

**Языки.** Русская версия — корень сайта, английская — `/en/`. Выбор языка сохраняется в `localStorage` (ключ `vn-lang`) только после нажатия на переключатель; при повторном визите на русскую главную посетитель, выбравший EN, попадает в английскую версию. При переключении сохраняется текущий раздел (`#projects` и т. д.) — id разделов в обеих версиях одинаковые.
